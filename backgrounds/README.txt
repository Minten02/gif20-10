HƯỚNG DẪN THÊM HÌNH NỀN CHO THIỆP GỬI CHỊ MOON

Đặt hình nền trong thư mục này, cùng cấp với file HTML ở thư mục bộ hoàn chỉnh.
Đặt tên theo số liên tục, ví dụ:
  bg1.jpg   (ảnh nền đầu tiên)
  bg2.mp4   (video nền dài 8–9 giây)
  bg3.webp  (ảnh nền tiếp theo)
  bg4.webm  (video nền khác, nếu muốn)

Định dạng ảnh: JPG, JPEG, PNG, WEBP, AVIF.
Định dạng video: MP4, WEBM, OGV. Khuyến nghị MP4 H.264 để tương thích tốt hơn.
Video nền sẽ tự chạy không tiếng và lặp lại khi tới lượt nền đó. Khi chuyển lời chúc, nền sẽ đổi theo số thứ tự.
Không bỏ số giữa chừng: nếu có bg1 và bg3 nhưng thiếu bg2 thì trang sẽ dừng dò ở bg2.
Giữ thư mục backgrounds cùng cấp với file HTML; mở HTML bằng Chrome hoặc Edge.
